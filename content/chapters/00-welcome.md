# Welcome

## Story

AI coding agents can now write and fix real software. Claude Code, Codex and
Gemini CLI are the best-known examples. But each one expects to run on a
developer's own laptop, one person at a time.

**Fountain gives every agent its own computer in the cloud, and lets any
product start one with a single request.**

This tour shows what that means in five short chapters. Each one has a live
demonstration and a one-line takeaway. If you want the technical detail, open
**Under the hood** on any chapter.

Use the arrow keys or the buttons below to move through the tour.

## Takeaway

Fountain turns coding agents from a desktop tool into something any product
can build on.
